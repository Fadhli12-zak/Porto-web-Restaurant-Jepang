# Japanese Restaurant Landing Page

A restaurant-themed landing page and reservation website built with **HTML**, **CSS**, and **JavaScript**.

## Live Demo
<https://fadhli12-zak.github.io/Porto-web-Restaurant-Jepang/>

## Overview
This project presents a restaurant brand website with a visual landing page, navigation sections, and a reservation page. It focuses on layout composition, visual presentation, and front-end website structure.

## Features
- Restaurant-style landing page
- Multiple content sections such as About, Menu, History, and Events
- Reservation page flow
- Responsive navigation behavior
- Visual branding using custom images and layout sections

## Tech Stack
- HTML
- CSS
- JavaScript

## Project Goal
This project was built as a portfolio-style front-end website to practice UI composition and branded web presentation.
